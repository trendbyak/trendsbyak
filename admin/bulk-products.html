🔄 Update Existing Products Using Excel

How this works:
Your Excel file must contain the product's existing SKU.
The system will find that SKU in your database and UPDATE the existing product.
No new products will be created.
Important:
Blank Excel cells mean DO NOT CHANGE.
To intentionally remove a value, enter CLEAR in that cell.

📊 Excel Format

Use the following column names in your Excel file.

Column Required? Example How it works
sku YES TBK-SCR-001 Used to find the existing product.
name No Premium Satin Scrunchie Updates product name.
price No 45 Updates regular price.
sale_price No 35 Updates sale price.
stock No 100 Updates inventory quantity.
category No Scrunchies Updates category.
collection No Best Sellers Updates collection.
description No Premium satin scrunchie Updates description.
image_url No https://... Updates product image URL.
status No active Updates product status.

Example:

If your database currently has:
SKU: TBK-SCR-001
Stock: 20
Price: 45

And your Excel contains:
SKU: TBK-SCR-001
Stock: 100
Price: blank

The result will be:
Stock → 100
Price → 45 remains unchanged
